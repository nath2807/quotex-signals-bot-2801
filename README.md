# Quotex Signals Bot

A Python-based trading signals bot for Quotex binary options platform. This bot generates trading signals based on technical analysis and sends notifications via Telegram.

## Features

- 🎯 Automated signal generation for multiple trading pairs
- 📱 Telegram notifications for real-time signal alerts
- ⚙️ Configurable confidence thresholds
- 📊 Support for multiple timeframes (1m, 5m, 15m, 30m, 1h)
- 📝 Comprehensive logging system
- 🔄 Continuous monitoring mode

## Installation

1. Clone this repository:
```bash
git clone https://github.com/nath2807/quotex-signals-bot-2801.git
cd quotex-signals-bot-2801
```

2. Install required dependencies:
```bash
pip install -r requirements.txt
```

3. Configure your environment:
```bash
cp .env.example .env
```

4. Edit the `.env` file with your settings:
```
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here
SIGNAL_INTERVAL=60
CONFIDENCE_THRESHOLD=70
TRADING_PAIRS=EURUSD,GBPUSD,USDJPY,BTCUSD
```

## Configuration

### Environment Variables

- `TELEGRAM_BOT_TOKEN`: Your Telegram bot token (get from [@BotFather](https://t.me/botfather))
- `TELEGRAM_CHAT_ID`: Your Telegram chat ID
- `SIGNAL_INTERVAL`: Time between signal generations in seconds (default: 60)
- `CONFIDENCE_THRESHOLD`: Minimum confidence level for signals 0-100 (default: 70)
- `TRADING_PAIRS`: Comma-separated list of trading pairs to monitor

### Getting Telegram Credentials

1. Create a bot by messaging [@BotFather](https://t.me/botfather) on Telegram
2. Use the `/newbot` command and follow instructions
3. Save the bot token provided
4. Get your chat ID by messaging [@userinfobot](https://t.me/userinfobot)

## Usage

### Run the bot:
```bash
python bot.py
```

### Run in background (Linux/Mac):
```bash
nohup python bot.py > output.log 2>&1 &
```

### Stop the bot:
Press `Ctrl+C` or kill the process

## Signal Format

Signals include the following information:
- 💱 Trading Pair (e.g., EURUSD)
- 📊 Direction (CALL/PUT)
- ⏰ Timeframe (1m, 5m, 15m, 30m, 1h)
- 💪 Confidence Level (percentage)
- 💰 Entry Price
- 🕐 Timestamp
